## 范围与统计口径

- 仅 TanStack Start，检查 3 个可索引页面及 2 个 noindex 法律页面。
- 主词暂按现有产品主题确定为 `zombie couple video`；生成器页暂对应 `zombie couple video generator`；教程页暂对应 `how to make a zombie couple video`。这些是当前主题与页面映射，不是付费关键词工具验证过的搜索量。
- 正文统计范围：main 内可见文本，排除生成器工具、表单、状态提示、导航和脚本；包含正文标题和相关链接。另列出 main 全部可见文本词数，以便与 AITDK 等工具不同的统计范围对照。正文不能用工具按钮和状态文案凑到 800 词。
- 英文单词按连续字母/数字及内部撇号、连字符计数；完整关键词忽略大小写匹配。
- **词组密度 = 完整关键词出现次数 ÷ 正文单词数 × 100%。** 另列目标词覆盖词数占比：出现次数 × 关键词单词数 ÷ 正文单词数。两者不能混称为同一指标。
- 50–60 / 150–160 / 800 词 / 3%–5% 按你的自定验收标准检查，不宣称它们是 Google 官方固定门槛。

## 优先问题

1. **首页与生成器页定位重复。** 两页 H1 完全相同、Description 完全相同、生成器和介绍也复用。目前只有标题后缀和 URL 的差异，没有足够独立内容支撑不同意图。先明确主页讲主词与产品整体、生成器页讲实际输入输出和使用条件、教程页讲步骤；不要新增更多变体页。
2. **三个可索引页正文都不足 800 词。** 生成器页去除界面后只有 61 词，是最薄的一页。正文与语义覆盖均需补充真实信息，而不是重复关键词。
3. **三个可索引页 Description 都未包含各自完整目标关键词。** 首页和生成器页 159 字符但文本重复；教程页仅 111 字符。
4. **首页 Title 为 65 字符，超过 50–60 的要求。** 主页应突出主词，生成器页与教程页标题应分别服务其目标词。所有页面都有且只有一个 H1。
5. **缺少面包屑和全部 JSON-LD。** 目前没有 BreadcrumbList、WebApplication、FAQPage 或 ImageObject。建议优先给内页加可见面包屑及一致的 BreadcrumbList；首页/生成器页增加与实际功能对应的 WebApplication，不添加虚构评分、下载量或评论。
6. **目前没有公开内容图片。** 不是缺 alt 的现有图片错误；当前初始 DOM 没有 img。用户上传预览有描述性 alt，但不是公开 SEO 内容图。等用户提供演示后，添加真实封面、相应 alt 与 ImageObject/VideoObject；本轮不生成图片或视频，也不伪造资产。
7. **正式域名尚未确定。** 当前 canonical、robots、sitemap 都使用本地预览源且路径自指正确；它们不是正式生产配置。发布前必须设置自己的 VITE_SITE_URL 并重新构建，不能发布 localhost 或竞争站域名。

## 已通过与适用性

- 五个现有公开页面均返回 HTTP 200；各页只有一个 H1，canonical 路径自指。
- 三个可索引页在关闭 JavaScript 后仍能看到 H1 和核心正文，SSR 实测通过。
- robots.txt 返回 200，Allow: /；sitemap.xml 返回 200，列出全部 3 个可索引页面。
- 两个法律页均是 noindex, follow，所以有意不进 sitemap。它们当前标题、描述、词数也不满足“每页同样阈值”，但建议保留合规职责，不为凑 SEO 指标塞主词。
